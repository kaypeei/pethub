# pethub
PetHub is an SDLC‑based project, and the work is the Software Development Life Cycle, specifically the requirements, design, development support, testing, and delivery phases.
Project PetHub aims to design and launch a user-friendly WooCommerce-based website that enables pet stores to sell products, manage vet appointment bookings, and share pet care content through an integrated, customer-focused platform.

<H1> PROJECT MANDATE <H1> </H1>
Project Title: WooCommerce Pet Store & Vet Appointment Site 
This project does not require coding. 


Project Overview: 
An e-commerce site for pet stores combined with vet appointment scheduling. 


Objectives: 
- Sell pet products. 

- Book vet sessions. 

- Provide pet care blog content. 


Key Features: 
- Product categories. 

- Booking system. 

- Customer dashboard. 

- Coupons and loyalty features. 


Tools / Tech Stack: 
- WooCommerce 

- Booking Plugins 

- Astra Theme
